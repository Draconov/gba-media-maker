# GBA Media Maker

**Перетворюйте відео, музику, анімовані GIF і зображення на ROM-файли Game Boy Advance — у Windows, macOS, Linux або прямо в браузері.**

[English](README.md) · **Українська**
</div>

## Яку версію вибрати

| | Браузерна версія | Портативний застосунок |
|---|---|---|
| Встановлення | Не потрібне | Завантажте пакет для своєї ОС і запустіть застосунок |
| Обробка | Локально у браузері через ffmpeg.wasm | Локально через нативний FFmpeg |
| Найкраще підходить | Швидкі та звичайні проєкти | Довгі відео, повторні задачі, максимальна швидкість |
| Приватність | Вихідні медіа не залишають пристрій | Вихідні медіа не залишають пристрій |
| Платформа | Сучасні десктопні браузери | Windows x64, універсальний macOS (Intel + Apple Silicon), Linux x86_64 |
| Вебдовідка | [Українська довідка](website/README.uk.md) | Цей файл |

Браузерна й десктопні версії для Windows, macOS та Linux використовують той самий формат проєкту, формат ROM, медіаменю, теми, титульні картки, режими аудіообкладинок і runtime плеєра. Великі проєкти краще конвертувати у десктопному застосунку через обмеження пам’яті браузера.

## Локалізація застосунку

Інтерфейс конвертера підтримує:

- **English**
- **Українська**

На першому запуску мова визначається за мовою системи/браузера. Вибір зберігається локально й використовується надалі. Якщо переклад для окремого повідомлення відсутній, застосунок показує англійський текст.

Локалізація стосується інтерфейсу десктопного застосунку для Windows/macOS/Linux та вебверсії. **Інтерфейс, який вбудовується у GBA ROM, наразі не локалізується.**

## Що можна створити

- звичайний `.gba` ROM з одним медіаелементом;
- ROM з **медіаменю**, що містить відео, GIF, музику та/або зображення;
- колекцію лише одного типу медіа, наприклад музичний альбом або галерею;
- окремі `.gba` файли, упаковані у ZIP;
- пронумеровані частини одного довгого відео, якщо воно не вміщується в один картриджний ROM.

Для нових проєктів колекції з двох або більше елементів автоматично відкриваються через медіаменю, якщо не вибрано режим окремих ROM.

## Підтримка медіа

### Відео

- MP4, MKV, MOV, AVI, WebM та інші формати, які підтримує FFmpeg;
- обрізання початку/кінця та зміна швидкості;
- Fit with bars, Crop to fill або Stretch;
- кілька частот кадрів, оптимізованих для GBA;
- спільна або покадрово/посценова палітра;
- вимкнений, ordered або error-diffusion дизеринг;
- keyframe/delta стиснення або нестиснене відео;
- вибір аудіодоріжки;
- mix/left/right/no-audio;
- нормалізація, limiter, PCM та експериментальний IMA ADPCM;
- loop, seek і save/resume;
- автоматичне розділення довгих відео;
- титульні картки між частинами;
- експериментальний режим Extreme optimization.

### GIF

GIF обробляється як анімоване відео, автоматично зациклюється та не має аудіокерування.

### Музика / аудіо

- MP3, WAV, FLAC, OGG/Opus, M4A, AAC та інші FFmpeg-сумісні формати;
- редаговані назва треку та виконавець;
- обрізання й зміна швидкості;
- PCM або експериментальний IMA ADPCM;
- pause/resume, seek, loop, volume, mute та save/resume;
- вбудована обкладинка, один із 20 стандартних пресетів або власне зображення.

Обкладинки зберігаються як нативне 240×160 RGB555 зображення.

### Зображення

Статичні зображення зберігаються без відеоквантування як 240×160 RGB555.

- PNG, JPEG, WebP, BMP, TIFF та інші формати FFmpeg;
- fit/crop/stretch;
- автоматичне слайдшоу з налаштованою тривалістю;
- ручний перегляд без слайдшоу.

## Дизайн медіаменю

- живий 120×80 preview тих самих даних, що потрапляють у ROM;
- `[V]`, `[A]`, `[I]` позначки типів медіа;
- Classic dark, Ocean Wave static/animated, Blue Wave animated;
- власне PNG/JPEG/WebP/GIF/відео тло;
- GIF/відеотло до 16 зациклених кадрів;
- налаштування кольору тексту, виділення та контуру;
- навігація D-pad по колонках/сторінках;
- запам’ятовування вибраного пункту при ввімкненому save/resume.

## Титульні картки для розділеного відео

Перед кожною частиною довгого відео можна показати 240×160 титульну картку:

- перший або вибраний кадр частини чи суцільний колір;
- затемнення;
- окремі налаштування заголовка й підзаголовка;
- спільні параметри або налаштування для кожної частини;
- запуск за таймером або після натискання `A`;
- optional skip/fade;
- pixel-accurate RGB555 preview.

## Латиниця та кирилиця в ROM

GBA runtime окремо від локалізації самого застосунку підтримує спільний 3×5 шрифт для латиниці, української та російської кирилиці.

- українські `Ґ Є І Ї`;
- російські `Ё Ъ Ы Э`;
- змішані Latin/Cyrillic назви;
- UTF-8 проєкти;
- ліміти за видимими glyph, а не UTF-8 байтами;
- повідомлення про непідтримувані символи;
- ASCII-транслітерація заголовка картриджа.

## Основне керування у ROM

### Відео та аудіо

| Кнопка | Дія |
|---|---|
| `A` | Pause / resume |
| `B` | Назад до медіаменю або restart у direct ROM |
| `L` / `R` | Попереднє / наступне медіа |
| D-pad `Left` / `Right` | Seek; у paused-відео — покадровий крок |
| D-pad `Up` / `Down` | Гучність, якщо медіа має аудіо |
| `SELECT` | Mute / unmute, якщо доступне аудіо |
| `START` | Перемикання HUD |
| `START + SELECT` | Екран допомоги |

### Зображення

| Кнопка | Дія |
|---|---|
| `A` | Pause / resume лише при активному slideshow |
| `B` | Назад до меню або restart |
| `L` / `R` | Попереднє / наступне медіа |
| `START` | Показати / сховати HUD |
| `START + SELECT` | Допомога |

## Проєкти

Файли `.gbamedia` зберігають налаштування проєкту та кожного медіаелемента.

У Windows, macOS і Linux десктопний застосунок може зберігати шляхи до вихідних файлів і повторно знаходити їх. У браузері доступ до довільних шляхів заборонений sandbox-моделлю браузера, тому після відкриття проєкту потрібно повторно вибрати ті самі файли; вони зіставляються за метаданими/назвою.

## FFmpeg

Десктопна версія спочатку шукає FFmpeg поруч із виконуваним файлом/у пакеті застосунку, потім у типових системних шляхах і `PATH`. Офіційні Windows/Linux релізи пакують pinned LGPL FFmpeg; macOS-реліз збирає FFmpeg з pinned upstream source з `libdav1d`. Вебверсія використовує `ffmpeg.wasm` локально в браузері.

## Десктопні релізи

- **Windows x64:** `GBA_Media_Maker_v*_Windows_x64.zip` → `GBA Media Maker.exe`.
- **macOS:** `GBA_Media_Maker_v*_macOS.zip` → `GBA Media Maker.app`. Застосунок і вбудований FFmpeg є Universal 2 та містять нативні Intel (`x86_64`) і Apple Silicon (`arm64`) slices.
- **Linux x86_64:** `GBA_Media_Maker_v*_Linux_x86_64.tar.gz` → `./gba-media-maker`. Цей реліз призначений для сучасних 64-бітних Linux-ПК на Intel/AMD. `./install-user.sh` встановлює застосунок для поточного користувача, додає desktop launcher і symlink `~/.local/bin/gba-media-maker`.

На macOS/Linux застосунок за замовчуванням відкриває той самий десктопний UI, що й Windows. CLI залишається доступним через `-input ...` або `--cli`.

## Розробка і тести

```bash
go test ./...
```

Вебверсія:

```bash
cd website
npm install
npm test
npm run build
```

Єдине джерело локалізації:

```text
locales/index.json
locales/en.json
locales/uk.json
```

`locales/index.json` — реєстр мов для десктопного застосунку та вебверсії. Щоб пізніше додати ще одну мову інтерфейсу, достатньо додати її каталог і запис у цьому manifest; окремо переписувати обидва перемикачі не потрібно. `website/public/locales/` генерується автоматично під час `dev`, `test` і `build` та не є джерелом перекладів.
