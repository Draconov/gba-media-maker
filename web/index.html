Lower values create smaller, more numerous ROMs.

Enable Split the video to choose a ROM-size target, an optional MM:SS duration limit, chapter-aware boundaries, title screens, and interrupted-job recovery. Videos that cannot fit one 32 MiB cartridge are still split automatically even when this option is off. Menu ROMs remember the selected item and save resume positions separately for each clip.

Playlist controls: SELECT+Left previous clip, SELECT+Right next clip. Other controls: A pause; B restart or menu; L/R seek; Left/Right seek or paused frame-step; Up/Down volume; SELECT mute; START HUD; START+SELECT help.
